# Trewrap — Product Requirements Document

> **Emotional Hook**: You traded 847 times last quarter. Your average hold time was 4 minutes. You are: Exit Liquidity Human.

## Problem Statement
Wallet analytics are boring tables. Nobody shares a Dune dashboard. But everyone shares a personality quiz result.

## Solution Overview
Spotify Wrapped-style persona cards from Dune SQL analysis. Input wallet → 5 behavioral signals → AI persona.

## Core Features (MVP)
1. **Wallet input → Dune SQL query execution**
2. **5 behavioral signals: timing, diversity, MEV, win rate, hold duration**
3. **AI persona generator (12 archetypes)**
4. **Shareable card with stats + roast**
5. **Leaderboard of most common personas**

## Success Metrics
- All SDK features demonstrably integrated
- Demo flow works end-to-end
- Live data where applicable (not mocked)

## Out of Scope
- ❌ Historical comparison
- ❌ Portfolio advice
- ❌ Real-time tracking
