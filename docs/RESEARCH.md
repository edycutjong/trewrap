## Mission
Build using **Dune SIM** — a real-time blockchain data API providing instant access to wallet balances, token metadata, transaction history, and on-chain activity across 60+ EVM chains and Solana. Single API key, no indexer setup.

## Track Scope & Focus Areas
- **Real-time Data Apps** — live blockchain data without indexing
- **Wallet Analytics** — balance, transaction, activity tracking
- **Token Intelligence** — metadata, pricing, classification
- **Webhook Subscriptions** — push data in real time
- **Cross-chain** — 60+ EVM chains + Solana from one API

## SDK / Integration Primitives
- Dune SIM API — single API key, structured blockchain data
- SVM endpoints (Solana-specific)
- EVM endpoints (60+ chains)
- Webhook subscriptions (real-time push)
- Decoded events, token metadata, USD pricing
- Classified transactions (DEX swaps, stablecoin transfers, bridge events)

## Submission Requirements
